Admin webu

Tu zmeníš texty, cenník, tím a fotky webu Barbershop 30. Zmeny sa uložia priamo na web a o minútu ich uvidia zákazníci.

Kľúč je heslo pre úpravy webu. Zadáš ho raz na tomto zariadení.

Ako získam kľúč

Kľúč vytvorí raz správca webu na účte, ktorému web patrí, a odovzdá ti ho osobne.

  1. Otvor github.com/settings/personal-access-tokens/new a prihlás sa účtom webu.
  2. Názov napr. Admin Barbershop, platnosť podľa seba (napr. 1 rok).
  3. Repository access: Only select repositories a vyber repozitár webu.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Klikni Generate token, kľúč skopíruj a vlož sem. Nikomu inému ho neposielaj.

Keď kľúč stratíš alebo ho niekto videl, správca ho na GitHube zmaže a vytvorí nový.
