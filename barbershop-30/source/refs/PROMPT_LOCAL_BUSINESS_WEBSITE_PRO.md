# Max Studio Ultra X — Local Business Website Pro Prompt

Use **Max Studio Ultra X** to create or improve a production-ready website for the local business described below.

## Inputs

- Business and category: [NAME + TYPE]
- Location(s) or service area: [PLACE]
- Primary customer: [AUDIENCE]
- Primary conversion: [BOOK / CALL / VISIT / TRIAL / MEMBERSHIP / ORDER / QUOTE]
- Services, menu, classes or memberships: [VERIFIED SOURCE OR FILES]
- Contact, address and hours: [VERIFIED SOURCE]
- Booking, ordering, timetable or CRM provider: [PROVIDER/LINK OR UNKNOWN]
- Brand assets and real media: [FILES/LINKS]
- Required language(s): [LANGUAGE]
- Existing site/repository/deployment: [LINK/PATH/UNKNOWN]
- Constraints and deadline: [DETAILS]

## Required operating mode

1. Inspect supplied files, repository, website, assets, and available tools before making claims.
2. Load `references/100-local-business-website-engine.md`, exactly one primary vertical reference—`101` gym/fitness, `102` café/hospitality, or `103` appointment/service—and `104` only when search, reviews, analytics, integrations, or ongoing operations are in scope.
3. Build a truth-source ledger. Mark missing facts for confirmation; never invent prices, hours, reviews, staff, credentials, amenities, availability, results, policies, integrations, or legal claims.
4. Classify the business model and choose one primary mobile conversion. Compile a concise page map, content requirements, integration boundary, visual direction, and measurable acceptance criteria.
5. Create an original visual system grounded in this business. Use real local evidence and a small number of purposeful signature interactions. Keep essential actions fast, accessible, and usable with reduced motion.
6. Implement the requested site or edits in the existing stack. Use semantic responsive components, maintained structured content, useful loading/error/empty states, and a safe third-party handoff.
7. Verify 375/390/430 mobile widths plus tablet and desktop; keyboard/focus; CTA journey; form or provider path; performance; metadata and structured data; analytics/consent if present; and no fabricated content.
8. Run the applicable vertical scenario test and one focused Creative Director pass. Fix the highest-impact issues before handoff.

## Delivery format

Return: implemented deliverable, selected modules, primary journey, truth-source gaps, integrations and fallbacks, verification evidence, deployment status only if actually performed, and the next client-owned action.
