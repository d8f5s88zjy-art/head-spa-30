# Shot list – čo treba nafotiť / natočiť

Zoznam médií, ktoré web potrebuje a v dodaných 45 fotkách nie sú. Každý záber
má rámovanie, pohyb, svetlo, orientáciu a miesto použitia. Všetko fotiť v
prevádzke pri bežnom osvetlení (oranžové lampy + denné svetlo), bez blesku.
