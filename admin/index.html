Vitaj v admine.

Tu zmeníš ceny, dĺžky a texty rituálov, otváracie hodiny, telefón, oznam a štatistiky. Po uložení sa web sám aktualizuje asi do dvoch minút.

Kľúč je heslo pre úpravy webu. Zadáš ho len raz na tomto zariadení.
Ako získam kľúč (raz, asi 2 minúty)
  1. Otvor github.com/settings/personal-access-tokens/new a prihlás sa.
  2. Token name: napíš „Admin webu“. Expiration: vyber 1 rok (Custom).
  3. Repository access: Only select repositories, vyber repozitár tohto webu.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Klikni Generate token, kľúč skopíruj a vlož sem. Nikomu ho neposielaj.

Obsah webu.

Zmenené polia sa zlato orámujú. Nič sa neuloží, kým dole neklikneš Uložiť na web.
