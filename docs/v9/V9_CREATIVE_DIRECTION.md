# V9 Creative Direction — HEAD SPA 30

## Creative spine

**Threshold → Water → Ritual → Choice → Quiet → Booking**

Web sa nemá cítiť ako zoznam sekcií. Má pôsobiť ako jedna pokojná cesta od zelených dverí k vode a od vody k rozhodnutiu rezervovať. Existujúca hero scéna už obsahuje správne stavebné prvky; V9 ich zjednocuje namiesto toho, aby pridával ďalší vizuálny chaos.

## Brand language

- tmavá lesná zelená a čierna ako priestor
- 24K zlatá iba ako vzácny akcent, nie plošná dekorácia
- vodová tyrkysová iba ako sekundárny pohybový signál
- Fraunces = rituál, atmosféra, editoriálnosť
- Manrope = informácia, cena, rezervácia, navigácia
- žiadne purple gradients, neon SaaS glow, náhodný glassmorphism ani generické 3-card patterny

## Five signature moments

1. **Door threshold** — zachovať existujúce otvorenie dverí, krátke a neblokujúce.
2. **Water journey** — zachovať scroll hero, zvýrazniť textovú hierarchiu a zlatý settle.
3. **Ritual spotlight** — jemná lokálna reakcia kariet na pointer, nie 3D cirkus.
4. **Quiet scene breaks** — veľké citáty fungujú ako strih medzi scénami.
5. **Booking resolution** — kontakt + finale majú byť najsilnejší pokojný vizuálny koniec.

## Conversion rule

Primárna akcia je rezervácia. Sekundárne sú rituály/cenník a poukaz. Vizualita nikdy nesmie prekryť cenu, dĺžku, telefón, adresu alebo booking CTA.

## Mobile rule

Mobil nie je zmenšený desktop. V9 vypína ambient pointer efekty, zjednodušuje atmosféru a necháva existujúci statický hero + mobile bar ako primárny konverzný rámec.
