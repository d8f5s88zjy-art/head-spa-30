## Source classes

| Class | What it establishes | What it does not establish |
|---|---|---|
| Creator-authored case study | Creator's account of project decisions and techniques | Current implementation of every future version |
| Award project page | Project identity, credited authors and submitted metadata | Guaranteed performance, conversion or current live state |
| Submission preview | Visible static composition at capture | Motion, functioning navigation or responsiveness |
| Social discovery metadata | A post URL and available caption/description | Completed watch, verified project identity or actual price |
| Repository metadata | Repository identity, status and declared license | Security, suitability or successful installation |
| Published prompt | Publicly available attributed text | Popularity, commercial success or a working generated site |

Do not repeat a provider's scene analysis when its description contradicts the caption. Several unrelated clips were incorrectly described as web design and were excluded.
