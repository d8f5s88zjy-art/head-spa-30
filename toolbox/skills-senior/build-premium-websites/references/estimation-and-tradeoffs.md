# 006 — Odhad práce a kompromisy

Use when choosing a scope, comparing production options or explaining cost. Treat prices in this skill as user-requested planning scenarios, not market valuations.

## Decide

Estimate the work required for an outcome, not the number of sections or effects. Distinguish a predictable implementation from an uncertain integration or missing media production. Compare a still image, pre-rendered shot and interactive scene by visitor benefit, production effort, runtime cost and future editing.

## Execute

Break work into deliverable slices with dependencies: content, design, media, functional integration, responsive behavior, verification and release. Use optimistic, expected and difficult scenarios where uncertainty matters; state what causes the spread. Separate build effort from licensing, hosting, content maintenance and recurring support. Use supplied rates or label illustrative rates explicitly.

Reduce uncertainty before padding every estimate: test one representative API operation, validate one model on the target device, or obtain the actual content inventory. Put contingency against a named risk. A deadline is a constraint, not evidence that the scope fits. Offer a concrete scope reduction with preserved user value when it does not.

## Verify

Check that review, correction, integration failure paths and handoff are included. Compare the proposed first slice with the available time and actual team capability. Do not translate a €400,000 ambition into an automatic enterprise stack or a €1,500 budget into an unsupported promise of custom 3D commerce.

## Deliver

Return a bounded scope, assumptions, effort range, recurring costs, excluded work and a condition for revising the estimate. Recommend one option and explain the tradeoff. Save actual effort lessons only when there is reliable project evidence; never manufacture historical estimates or a return on investment.
