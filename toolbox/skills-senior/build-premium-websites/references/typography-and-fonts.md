# 023 — Typografia a fonty

Use when type hierarchy, readability or font loading limits the design. Treat the font file, license and language coverage as production inputs.

## Decide

Choose roles before families: display, body, interface, numeric data and occasional accent. Select contrast in scale, weight and rhythm that suits the actual copy. Avoid using many families to manufacture identity. Confirm Slovak glyphs and any required scripts from real files or authorized previews.

## Execute

Set a bounded type scale, line-height, measure and wrapping behavior. Tune heading breaks at representative widths; do not hardcode line breaks that damage translation. Use tabular figures where changing numbers should align. Keep essential text as text, with a correct accessible reading order.

Prepare licensed webfont subsets and weights actually used. Define a suitable fallback and inspect its metrics so loading does not destroy composition. Schedule animation measurement after the relevant font settles, with a usable timeout/fallback. Avoid splitting a heading into dozens of accessible fragments for character animation.

## Verify

Inspect long Slovak titles, accents, numerals, zoom, font failure and narrow viewports. Compare the first paint with the final font. Check overflow and readability in dense UI as well as the hero. Review actual contrast and focus; beautiful letterforms alone do not establish accessibility.

## Deliver

Supply role tokens, responsive ranges, font sources/licenses, loading strategy and examples. Record any intentional display treatment that must not spread to forms or paragraphs. Use the designer typography prompt when commissioning alternatives; require real text and a fallback specimen, not only a title on an empty board.
