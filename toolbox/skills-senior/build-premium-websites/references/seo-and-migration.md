# 091 — SEO a migrácia adries

Use when public content must be discoverable or existing addresses change. Preserve truthful, useful content and technical continuity.

## Decide

Identify indexable pages, language variants, canonical identity and valuable existing destinations. Separate search discoverability from ranking promises. Decide which old pages have genuine replacements; do not redirect every removed URL to the homepage without considering intent.

## Execute

Provide meaningful titles, headings, links, status codes and metadata. Keep important content available through the chosen render strategy. Use structured data only when it matches real visible content and current supported rules. Avoid invented reviews, services or geographic claims.

For migration build an old-to-new URL map, update internal links and coordinate canonical, sitemap, robots and redirects. Keep staging indexing controls from leaking into production. Preserve relevant assets and link relationships. Plan monitoring of missing pages and indexing after the authorized release.

## Verify

Inspect representative direct requests, redirects, status codes and rendered content. Check unexpected chains, loops and wrong destinations. Validate the deployed configuration rather than only local markup. Use current official search guidance for feature-specific requirements.

## Deliver

Provide metadata rules, migration map, executed checks and post-release observation plan. Keep actual traffic/ranking evidence separate from implementation claims. A technically clean migration reduces avoidable disruption but does not guarantee search positions or a growth percentage.
