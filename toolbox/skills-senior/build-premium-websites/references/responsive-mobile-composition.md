# 057 — Mobilná kompozícia a dotyk

Use whenever the website must work beyond the desktop artboard. Mobile is a composition and interaction decision, not a scaled screenshot.

## Decide

Choose the essential subject, message and action at narrow widths. Decide which desktop relationships reflow, simplify or become sequential. Remove hover dependencies and excessive camera travel. Preserve the full visitor task even if the visual technique changes.

## Execute

Use actual portrait assets or deliberate crops with a safe focal point. Define behavior between breakpoints, including short landscape viewports. Account for browser chrome, safe areas, the on-screen keyboard and text enlargement. Avoid forcing essential controls into a fixed viewport-height scene.

Keep touch targets stable and permit normal scrolling. Use pointer capabilities rather than width alone to infer hover behavior. Budget graphics quality, data transfer and decode work. A simpler poster with excellent composition is a valid intentional mobile mode when it retains the message.

## Verify

Inspect intermediate widths, orientation changes, keyboard-open forms, long copy and reduced motion. Check sticky overlays, bottom controls and focus visibility. Separate responsive emulation from actual physical-device observations in the evidence. Do not claim all mobile devices from one screenshot.

## Deliver

Provide mobile composition, crop rules, responsive transitions, input behavior and quality/fallback tiers. Require mobile states in designer briefs before final desktop polish. A handoff is incomplete if it leaves every narrow-screen decision to improvisation during coding.
