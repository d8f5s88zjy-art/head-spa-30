# 024 — Mriežka, proporcie a kompozícia

Use when a page feels generic, crowded or unstable across content lengths. Build a system of relationships rather than a sequence of identical boxes.

## Decide

Choose the dominant element and the supporting reading path for each section. Set container width, gutters, alignment anchors and spacing rhythm. Let content determine where asymmetry helps. Reserve intentional exceptions for meaningful visual emphasis.

## Execute

Compose a stable hero, dense information section and decision section with real copy. Use layout primitives that can accommodate intrinsic size and content growth. Separate decorative layering from document flow. Reserve image dimensions and avoid absolute positioning essential text against an unpredictable crop.

Define breakpoint changes by failure of composition, not device names alone. Recompose relationships on mobile: a subject may move above the copy, a horizontal comparison may become labeled groups, and a pinned scene may become sequential sections. Preserve source order and action priority. Treat spacing values as a coherent scale with documented exceptions.

## Verify

Resize between the designed widths, not just at the endpoints. Exercise one/many items, long labels, missing imagery and text enlargement. Check accidental overflow, overlapping layers and focus obstruction. Inspect still frames at the start, middle and end of animated layouts.

## Deliver

Provide layout constraints, alignment rules, responsive transitions and content resilience examples. A designer handoff should explain what stretches, wraps, stays fixed or changes order. Do not deliver only fixed desktop pixels and expect the developer to invent all intermediate behavior.
