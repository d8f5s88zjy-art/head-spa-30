# 011 — Analýza referencií a prenos princípov

Use when learning from a website, image or video reference. A reference should answer a design question, not dictate the entire finished site.

## Decide

Select complementary references for composition, motion and functional structure. State the visitor need each informs. Record whether evidence comes from a static image, video, live interaction, source code or documentation. A still cannot establish easing, reverse scroll or mobile behavior.

## Execute

For each selected reference note dominant subject, hierarchy, spacing rhythm, typography roles, media crop, transition mechanism and action visibility. If interaction tools are authorized and available, inspect one meaningful sequence: enter, pause, reverse, skip and narrow-screen adaptation. Use web retrieval for factual research and supported browser controls for interaction; do not bypass an unavailable control surface.

Translate the observation into a principle and an original application. “The subject remains anchored while context changes” is transferable; copying distinctive assets, text and a complete layout is not necessary. Preserve attribution and rights. Separate a proposed reconstruction from observed implementation; a WebGL-looking effect may be pre-rendered video.

## Verify

Compare the adaptation with actual content and device constraints. Reject references that require unavailable imagery or bury the user's core action. Check one stable frame without animation: weak hierarchy is not repaired by a dramatic transition. Mark uninspected reference conditions explicitly.

## Deliver

Provide a small evidence board: source, evidence class, useful mechanism, proposed adaptation and limitation. Load the existing W/FX catalogs selectively. Do not claim that cataloging 100 examples means all their code, live behavior or business results have been validated.
