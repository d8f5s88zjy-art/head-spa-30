# 021 — Informačná architektúra

Use when content is difficult to find or a redesign changes page structure. Start from user questions and content ownership, not a fashionable section order.

## Decide

Choose what belongs on one page, what needs its own address and which information must be available before a decision. Separate public discovery from authenticated work. A long scroll is appropriate only if the sequence clarifies a story; essential comparison or reference material may need direct access.

## Execute

Inventory actual content, merge duplicates and identify missing answers. Map page purpose, primary heading, entry points, related pages and action. Use stable meaningful URLs. Give pricing, location, availability or documentation the prominence their visitor task requires. Preserve existing valuable destinations when restructuring.

Define navigation labels from user language and verify that sibling labels have comparable scope. Use headings to describe content, not visual size. In a cinematic document, make chapters linkable and provide a route past the sequence. Keep editorial ownership alongside the structure so obsolete sections do not remain indefinitely.

## Verify

Walk representative find-and-act tasks from search, a deep link and the homepage. Check that no important answer exists only inside a hover, canvas or unavailable video. Test navigation on a narrow viewport and with keyboard focus. Compare old and new URL coverage before migration.

## Deliver

Provide the page/content map, primary journeys, navigation labels and redirect needs. Link to the relevant CMS schema and SEO plan when those are in scope. Avoid expanding a small business page into dozens of thin pages purely to increase the apparent project size.
